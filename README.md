# Baruch-Ermi LLC - Creative Financing Offer & Pitch Generator

An interactive real estate deal analyzer and offer generator built for **Baruch-Ermi LLC**. This application automates analyzing creative financing structures—specifically **Subject-To acquisitions** and **Seller Financing**—by calculating entry fees, net monthly cash flow, and deal viability metrics, then generating professional offer pitches for listing agents.

## Features
- **Deal Viability Analysis:** Calculates entry fees, net monthly cash flow, cash-on-cash return, and LTV.
- **Dynamic Offer Scripting:** Generates tailored, professional email pitches addressed to sellers or listing agents.
- **Scenario Presets:** Instant loading for Turnkey Sub-To, Strong Seller Financing, and Tight Margin scenarios.

## Tech Stack
- **Framework:** React / TypeScript (Vite)
- **Styling:** Tailwind CSS
- **AI Integration:** Google AI Studio / Gemini 3.8 Flash
